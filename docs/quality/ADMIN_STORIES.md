# Admin Stories

## ADM-001 : Tableau de bord admin
En tant qu'administrateur, je veux accéder à un tableau de bord listant les demandes d'accès en attente afin de les traiter.

## ADM-002 : Validation KYC
En tant qu'administrateur, je veux voir les documents KYC soumis, les approuver ou les rejeter avec un motif, afin de valider l'identité des membres.

## ADM-003 : Validation Broker
En tant qu'administrateur, je veux voir les vidéos broker soumises, les approuver ou les rejeter avec un motif, afin de valider les comptes de trading.

## ADM-004 : Gestion des accès
En tant qu'administrateur, je veux approuver ou rejeter les demandes d'accès aux groupes de diffusion afin de contrôler les inscriptions.

## ADM-005 : Création de signal
En tant qu'administrateur, je veux créer un signal de trading avec contenu, images et audience ciblée afin de le publier aux membres.

## ADM-006 : Publication de signal
En tant qu'administrateur, je veux publier un signal immédiatement ou le programmer, afin de contrôler le moment de diffusion.

## ADM-007 : Édition de signal
En tant qu'administrateur, je veux modifier un signal existant (versioning) afin de corriger ou mettre à jour son contenu.

## ADM-008 : Gestion des templates
En tant qu'administrateur, je veux créer des templates de signaux réutilisables afin de gagner du temps.

## ADM-009 : Statistiques de signal
En tant qu'administrateur, je veux voir les statistiques de lecture d'un signal (nb de vues, membres uniques) afin de mesurer son impact.

## ADM-010 : Journal d'audit
En tant qu'administrateur, je veux consulter les actions des administrateurs et les événements système afin de superviser la plateforme.
