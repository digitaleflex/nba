# Versioning

> **Version:** 1.0

## Semantic Versioning

The project follows [Semantic Versioning 2.0](https://semver.org/):

- **MAJOR** — breaking changes (architecture, database, API contracts)
- **MINOR** — new features, no breaking changes
- **PATCH** — bug fixes, documentation updates

## Current Version

**1.0.0** — Initial documentation and architecture

## Versioning Rules

- ADRs are versioned independently (ADR-NNN)
- Database migrations are versioned by timestamp
- API versions follow the application version
- Documentation version matches the application version
