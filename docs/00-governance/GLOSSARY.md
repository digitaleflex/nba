# Glossary

> **Version:** 1.0

| Term | Definition |
|------|------------|
| **ADR** | Architecture Decision Record — a documented architectural choice |
| **BullMQ** | Background job queue backed by Redis |
| **Better Auth** | Authentication library for Next.js |
| **KYC** | Know Your Customer — identity verification process |
| **Member** | Platform user with MEMBER role |
| **Modular Monolith** | Single deployment with isolated business modules |
| **Neon** | Managed PostgreSQL provider |
| **Prisma** | ORM for TypeScript and Node.js |
| **RBAC** | Role-Based Access Control |
| **Resend** | Transactional email service |
| **Server Action** | Next.js server-side function called from the client |
| **Signal** | Trading signal published to members |
| **Shadcn UI** | Component library built on Radix UI and Tailwind |
| **Zod** | TypeScript-first schema validation library |
