# Brand Guidelines

> **Version:** 1.0

## Name

NeverBrokeAgain (NBA)

## Logo

- Provided as SVG in `public/images/`
- Light and dark variants
- Favicon in `public/images/favicon.ico`

## Colors

| Token | Value | Usage |
|-------|-------|-------|
| Primary | Blue (#2563eb) | CTAs, links, active states |
| Success | Green (#16a34a) | Approved, verified |
| Warning | Amber (#d97706) | Pending, attention |
| Destructive | Red (#dc2626) | Errors, rejected, delete |
| Background | White → Slate 950 | Light → dark mode |

## Typography

- Font: Inter
- Fallback: system-ui, sans-serif
- Monospace: JetBrains Mono (code only)

## Voice

- Professional but approachable
- Clear and direct
- Use active voice
- Avoid jargon in user-facing text
