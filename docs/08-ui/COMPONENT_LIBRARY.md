# Component Library

> **Version:** 1.0

## Shadcn UI Components

Available components from Shadcn UI:

| Component | Location |
|-----------|----------|
| Button | `components/ui/button.tsx` |
| Input | `components/ui/input.tsx` |
| Card | `components/ui/card.tsx` |
| Dialog | `components/ui/dialog.tsx` |
| Table | `components/ui/table.tsx` |
| Dropdown Menu | `components/ui/dropdown-menu.tsx` |
| Avatar | `components/ui/avatar.tsx` |
| Badge | `components/ui/badge.tsx` |
| Select | `components/ui/select.tsx` |
| Tabs | `components/ui/tabs.tsx` |

## Application Components

| Component | Location | Purpose |
|-----------|----------|---------|
| DataTable | `components/shared/data-table.tsx` | Paginated table with sorting |
| EmptyState | `components/shared/empty-state.tsx` | Empty state display |
| ErrorState | `components/shared/error-state.tsx` | Error display with retry |
| ConfirmDialog | `components/shared/confirm-dialog.tsx` | Confirmation dialog |
| SearchInput | `components/shared/search-input.tsx` | Debounced search |

## Adding Components

```bash
npx shadcn@latest add button
npx shadcn@latest add dialog
```
